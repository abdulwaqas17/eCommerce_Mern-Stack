+++++++++++++++++++++++++++++++++++ MULTER +++++++++++++++++++++++++++++++++++++++++
### Line 1:
```javascript
const multer = require("multer");
```
- Yahan tum **Multer** ko import kar rahe ho.
- **Multer** ek **Node.js middleware** hai jo **form-data** (specially **file uploads**) handle karta hai.
- Jab user koi image ya file upload karta hai, Multer us file ko server par receive karne me help karta hai.

---

### Line 2:
```javascript
const storage = multer.diskStorage({});
```
- Yahan tum **storage engine** define kar rahe ho.
- `diskStorage({})` ka matlab hai:
  - File tumhare **server ke local disk** (computer ke andar) me temporarily save hogi.
  - `{}` ka matlab hai **default options** use kar rahe ho (koi custom filename ya path set nahi kiya abhi).

⚡ Normally, yahan tum path aur filename customize kar sakte ho jaise:
```javascript
diskStorage({
  destination: function (req, file, cb) {
    cb(null, 'uploads/');
  },
  filename: function (req, file, cb) {
    cb(null, Date.now() + '-' + file.originalname);
  }
});
```
Lekin tumne simple empty object `{}` rakha hai, jo theek hai jab tum temporary upload karte ho aur baad me Cloudinary pe bhejte ho.

---

### Line 3:
```javascript
const upload = multer({ storage });
```
- **`multer({ storage })`** se ek middleware create hua jiska kaam hai:
  - **Request me jo file upload hui hai, usko process karna**.
  - Aur **req.file** ya **req.files** me uska data daal dena.

---

### Line 4:
```javascript
module.exports = upload;
```
- Yahan tum `upload` ko export kar rahe ho.
- Taa'ke jab koi route banaoge jaise:
```javascript
router.post("/add-product", upload.fields([{name: 'image1'}, {name: 'image2'}]), controllerFunction);
```
to Multer middleware **request aane se pehle file ko handle karega**, aur tumhare controller tak images pohcha dega.

----------------------------------- Status -------------------------------------------
Code | Name | Use Case
200 | OK | Request sahi gaya aur response mila (e.g. product added, login success)
201 | Created | Naya resource create hua (e.g. new user, new product)
204 | No Content | Response sahi hai magar data nahi (e.g. delete success)
400 | Bad Request | Client ki taraf se input galat (e.g. required fields missing)
401 | Unauthorized | User authenticated nahi (e.g. token missing/invalid)
403 | Forbidden | Access mana hai (e.g. non-admin trying to access admin panel)
404 | Not Found | Resource nahi mila (e.g. wrong URL or product ID not found)
409 | Conflict | Duplicate data (e.g. user already exists)
422 | Unprocessable Entity | Valid request, lekin business logic galat (e.g. price < 0)
500 | Internal Server Error | Server side koi bug/crash ho gaya
